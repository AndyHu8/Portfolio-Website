
# Portfolio Website

Mein persönliches Portfolio zur Präsentation meiner Fähigkeiten, Erfahrungen und Projekte als Junior Frontend Developer.
Die Website wurde mit React entwickelt und dient sowohl als persönliche Online-Präsenz als auch als Plattform zur Vorstellung meiner bisherigen Arbeiten.

## 🌐 Live Demo

[Portfolio Website](YOUR_LIVE_URL)

## 🚀 Technologien

- HTML5 – Struktur der Website
- CSS3 – Styling, Layouts und Animationen
- JavaScript – Interaktionen und Funktionalität
- React – Komponentenbasierte Entwicklung
- GitHub REST API – Abrufen ausgewählter GitHub-Repositories
- EmailJS – Versand von Nachrichten über das Kontaktformular

## ✨ Features

- Responsive Design für verschiedene Bildschirmgrößen
- Vorstellung meiner Person und beruflichen Erfahrungen
- Übersicht meiner Fähigkeiten und Kenntnisse
- Dynamische Darstellung ausgewählter GitHub-Projekte über die GitHub REST API
- Individuelle Projektkarten mit Vorschaubildern und Technologietags
- Kontaktformular mit EmailJS
- Separates Impressum und Datenschutzerklärung

## ⚙️ Installation

Repository klonen:

```bash
git clone https://github.com/AndyHu8/portfolio-website.git
```

In das Projektverzeichnis wechseln:

```bash
cd portfolio-website
```

Abhängigkeiten installieren:

```bash
npm install
```

Entwicklungsserver starten:

```bash
npm start
```

Die Website ist anschließend standardmäßig unter http://localhost:3000 erreichbar.

```text
http://localhost:3000
```
